先运行 Start with codebaby doctor，它会检查浏览器、adb、代理等运行环境是否就绪。. It checks that the browser, adb, proxy and other prerequisites are in place.

常见问题Common questions

提示找不到 Chrome 或 Edge。It says Chrome or Edge cannot be found.

Web 用例需要本机装有 Chrome、Edge 或 Chromium。运行 Web cases need Chrome, Edge or Chromium installed. Run codebaby doctor 看检测结果；也可以连接 Docker 或云端的远程浏览器。 to see what was detected, or connect to a remote browser in Docker or the cloud.

Android 用例连不上设备。Android cases cannot reach the device.

确认已安装 adb，设备已开启 USB 调试并授权这台电脑，Make sure adb is installed, USB debugging is on and this computer is authorized, and adb devices 能看到它。 lists the device. codebaby doctor 也会检查。远程模拟器和云手机通过 adb 连接后同样可用。 checks this too. Remote emulators and cloud phones work once connected through adb.

请求要走代理，怎么配？My requests need a proxy.

命令行默认跟随系统代理；The CLI follows the system proxy by default. Use codebaby proxy 查看和设置，也可以用 to view or set one, or --proxy / --no-proxy 临时指定。桌面端在项目设置和标题栏里可以配置和开关。支持 socks5、socks5h 和 http。 for a single run. The desktop app has a proxy section in project settings and a toggle in the title bar. socks5, socks5h and http are supported.

退出码 0、1、2 分别是什么？What do exit codes 0, 1 and 2 mean?

For codebaby verify：0 表示全部通过，1 表示有用例失败，2 表示无法完成验证（例如配置有误、服务不可达）。: 0 means everything passed, 1 means a case failed, 2 means verification could not complete (for example a configuration error or an unreachable service).

怎么让 AI 帮我写用例？How do I get AI to write cases for me?

让它先读 Have it read codebaby guide，那是一页写法速查。桌面端项目菜单里有“复制用例写法速查”，可以直接贴进对话。写完后 , a one-page cheat sheet. The desktop project menu has “Copy case cheat sheet” to paste into a chat. Afterwards codebaby validate 会检查并给出建议， checks the result and suggests fixes, and codebaby fmt --fix 可以一键改写。 rewrites them.

怎么升级？How do I upgrade?

命令行运行 Run codebaby upgrade；桌面端有新版本时状态栏会提示。也可以从 in the CLI; the desktop app shows a notice when a new version is available. You can also download again from the 下载页download page重新下载。.
