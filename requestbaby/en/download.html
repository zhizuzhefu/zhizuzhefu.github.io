Each package has a matching .sha256 file for checking the download. The desktop app is for macOS; the CLI covers macOS and Linux.

Install

Desktop app

Open the DMG and drag requestbaby into Applications. The app bundles the CLI: choose “Install command-line tool” from the menu and requestbaby works in your terminal.

Command line

Apple silicon macOS shown; use the matching file name for other platforms:

curl -LO https://github.com/zhizuzhefu/requestbaby/releases/latest/download/requestbaby-aarch64-apple-darwin.tar.gz
tar -xzf requestbaby-aarch64-apple-darwin.tar.gz
sudo mv requestbaby /usr/local/bin/
requestbaby --version

On Linux use the same tar.gz flow with the matching file name.

Verify the download

curl -LO https://github.com/zhizuzhefu/requestbaby/releases/latest/download/requestbaby-aarch64-apple-darwin.tar.gz.sha256
shasum -a 256 -c requestbaby-aarch64-apple-darwin.tar.gz.sha256

Upgrade

Run requestbaby upgrade to download the latest version, verify it and replace itself; add --check to only check. The desktop app checks at launch and shows a notice in the status bar when a new version is out.

Requirements

  • Web cases need Chrome, Edge or Chromium on the machine, or a remote browser.
  • Android cases need adb and a device or emulator with debugging enabled.
  • requestbaby doctor checks that all of this is in place.

Build from source

Needs Rust (rustup) and cmake. The source is on GitHub.

After installing

A few commands get you a first result:

requestbaby init myapi && cd myapi
requestbaby vars set baseUrl http://localhost:8080 -e dev
requestbaby run
requestbaby open

If something goes wrong, see the support page.
