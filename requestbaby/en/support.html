Support & FAQ

Start with requestbaby doctor. It checks that the browser, adb, proxy and other prerequisites are in place.

Common questions

It says Chrome or Edge cannot be found.

Web cases need Chrome, Edge or Chromium installed. Run requestbaby doctor to see what was detected, or connect to a remote browser in Docker or the cloud.

Android cases cannot reach the device.

Make sure adb is installed, USB debugging is on and this computer is authorized, and adb devices lists the device. requestbaby doctor checks this too. Remote emulators and cloud phones work once connected through adb.

My requests need a proxy.

The CLI follows the system proxy by default. Use requestbaby proxy to view or set one, or --proxy / --no-proxy for a single run. The desktop app has a proxy section in project settings and a toggle in the title bar. socks5, socks5h and http are supported.

What do exit codes 0, 1 and 2 mean?

For requestbaby verify: 0 means everything passed, 1 means a case failed, 2 means verification could not complete (for example a configuration error or an unreachable service).

How do I get AI to write cases for me?

Have it read requestbaby guide, a one-page cheat sheet. The desktop project menu has “Copy case cheat sheet” to paste into a chat. Afterwards requestbaby validate checks the result and suggests fixes, and requestbaby fmt --fix rewrites them.

How do I upgrade?

Run requestbaby upgrade in the CLI; the desktop app shows a notice when a new version is available. You can also download again from the download page.

Documentation

The docs install with the program, so they always match your version: requestbaby guide <topic>. The same content is in docs/guide on GitHub, covering assertions, variables and environments, flows and data-driven runs, gRPC / WebSocket, Web / Android UI checks, proxy and every command.

Report a problem or suggest something

Please file it on GitHub Issues. Including the output of requestbaby --version and requestbaby doctor speeds things up. Remove passwords, tokens and other secrets before pasting cases or logs.
