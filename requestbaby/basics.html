快速上手：发送你的第一个请求

用过 Postman 的话，几分钟就能上手。桌面端用表单填写请求，不用先学 JSON；填好的内容保存成普通文件，可以放进 git，也可以交给命令行批量运行。

下载 requestbaby从 Postman 过来

五步发出第一个请求

  1. 下载并打开桌面端，选「新建项目」，起个名字。
  2. 点侧栏的「新建」→ 用例，协议选 HTTP / HTTPS，填名称和地址。也可以直接粘贴浏览器里「Copy as cURL」复制的命令。
  3. 在「请求」页填写方法、地址、查询参数、请求头和 Body。每一项都有开关，临时不想发的可以关掉，不用删。
  4. 点右上角「发送」，在响应区看状态码、耗时、响应体（格式化或原始）、响应头，以及等价的 cURL 命令。
  5. 在响应的「字段」页，把鼠标移到想验证的字段上，点「断言值」「断言类型」生成断言，或点「捕获…」把值存成变量给后面的请求用。然后点「运行全部」，一次跑完所有用例。

想用命令行：requestbaby init myapi 生成项目，requestbaby send <用例文件> 发一次，requestbaby run 跑全部。

日常调接口会用到的

构造请求

任意 HTTP 方法，地址、查询参数、请求头逐项编辑。Body 支持 JSON、x-www-form-urlencoded、form-data（含文件上传）和 raw 文本，顺序和 Postman 一致。

环境与变量

dev / test / prod 各有一套地址和账号，请求里写 {{baseUrl}} 引用。密码、token 可以标为 secret，只保存在本机，日志和报告里显示为 ****。

接口之间传值

登录拿到的 token 存成变量，后面的请求直接用。Cookie 会自动保存并带上。集合里写一次公共请求头（比如 Authorization），目录下的用例都会继承。

批量运行与结果

「运行全部」一次跑完，每个用例是通过还是失败一目了然；失败会写明断言了什么、期望什么、实际是什么。还能串成流程，或用 CSV / JSON 的多组数据重复运行，并保留运行历史。

高级设置

每个请求可以单独设置超时、重试、是否跟随重定向、是否忽略证书错误；整个项目可以统一走 socks5 / http 代理，也可以一键关掉。

导入现有内容

从 cURL、Postman 集合、OpenAPI / Swagger 导入现成的接口，不用从头录入。除了 HTTP，还能测 gRPC 和 WebSocket。

从 Postman 过来：概念对照

Postmanrequestbaby
Collection / Folder（集合、文件夹）集合：collections/ 下的目录，一个用例一个 JSON 文件
Request（请求）用例
Environment / Globals（环境、全局变量）环境（dev / test / prod）与变量，写法同样是 {{变量}}
Tests 里的断言「断言」页：状态码、响应头、响应体任意字段
Pre-request / Tests 脚本「脚本（进阶）」页：JS 脚本，API 与 pm.* 不同
Collection Runner / Newman「运行全部」，命令行 requestbaby run / verify
Import（导入）导入 cURL、Postman、OpenAPI / Swagger（Postman 里的脚本不会迁移）
Code snippet（代码片段）响应区的 cURL 页（目前只有 cURL）
Workspace 同步与分享用例是普通文件，用 git 共享和评审

目前还没有的

requestbaby 覆盖的是个人日常调接口和接口验收的核心流程，但不是 Postman 的全部。下面这些目前没有，请按需选择：

  • 内置的 OAuth 2.0、Digest、AWS 签名向导。Bearer、API Key 直接写在请求头里，Basic 可以用脚本里的 base64 工具生成，复杂签名用脚本。
  • Postman 脚本（pm.*）的自动迁移。导入时会提示哪些用例需要手工改写。
  • GraphQL 专用编辑器和 Socket.IO（GraphQL 可以用 JSON Body 发送）。
  • Mock Server、定时监控、在线文档发布、云端团队空间。
  • 导出为 Postman 格式，以及多语言的代码片段。
  • Windows 版本。
