requestbaby · 支持Support

支持与常见问题Support & FAQ

先运行 requestbaby doctor，它会检查浏览器、adb、代理等运行环境是否就绪。Start with requestbaby doctor. It checks that the browser, adb, proxy and other prerequisites are in place.

常见问题Common questions

提示找不到 Chrome 或 Edge。It says Chrome or Edge cannot be found.

Web 用例需要本机装有 Chrome、Edge 或 Chromium。运行 requestbaby doctor 看检测结果；也可以连接 Docker 或云端的远程浏览器。Web cases need Chrome, Edge or Chromium installed. Run requestbaby doctor to see what was detected, or connect to a remote browser in Docker or the cloud.

Android 用例连不上设备。Android cases cannot reach the device.

确认已安装 adb，设备已开启 USB 调试并授权这台电脑，adb devices 能看到它。requestbaby doctor 也会检查。远程模拟器和云手机通过 adb 连接后同样可用。Make sure adb is installed, USB debugging is on and this computer is authorized, and adb devices lists the device. requestbaby doctor checks this too. Remote emulators and cloud phones work once connected through adb.

请求要走代理，怎么配？My requests need a proxy.

命令行默认跟随系统代理；requestbaby proxy 查看和设置，也可以用 --proxy / --no-proxy 临时指定。桌面端在项目设置和标题栏里可以配置和开关。支持 socks5、socks5h 和 http。The CLI follows the system proxy by default. Use requestbaby proxy to view or set one, or --proxy / --no-proxy for a single run. The desktop app has a proxy section in project settings and a toggle in the title bar. socks5, socks5h and http are supported.

退出码 0、1、2 分别是什么？What do exit codes 0, 1 and 2 mean?

requestbaby verify：0 表示全部通过，1 表示有用例失败，2 表示无法完成验证（例如配置有误、服务不可达）。For requestbaby verify: 0 means everything passed, 1 means a case failed, 2 means verification could not complete (for example a configuration error or an unreachable service).

怎么让 AI 帮我写用例？How do I get AI to write cases for me?

让它先读 requestbaby guide，那是一页写法速查。桌面端项目菜单里有“复制用例写法速查”，可以直接贴进对话。写完后 requestbaby validate 会检查并给出建议，requestbaby fmt --fix 可以一键改写。Have it read requestbaby guide, a one-page cheat sheet. The desktop project menu has “Copy case cheat sheet” to paste into a chat. Afterwards requestbaby validate checks the result and suggests fixes, and requestbaby fmt --fix rewrites them.

怎么升级？How do I upgrade?

命令行运行 requestbaby upgrade；桌面端有新版本时状态栏会提示。也可以从下载页重新下载。Run requestbaby upgrade in the CLI; the desktop app shows a notice when a new version is available. You can also download again from the download page.

文档Documentation

文档随程序一起安装，版本始终和你装的一致：requestbaby guide <主题>。同样的内容在 GitHub 的 docs/guide，涵盖断言、变量与环境、流程与数据驱动、gRPC / WebSocket、Web / Android 界面验收、代理和全部命令。The docs install with the program, so they always match your version: requestbaby guide <topic>. The same content is in docs/guide on GitHub, covering assertions, variables and environments, flows and data-driven runs, gRPC / WebSocket, Web / Android UI checks, proxy and every command.

反馈问题或建议Report a problem or suggest something

请到 GitHub Issues 提交。附上 requestbaby --version 和 requestbaby doctor 的输出会让定位快很多；贴用例或日志之前，请先去掉密码、token 等敏感信息。Please file it on GitHub Issues. Including the output of requestbaby --version and requestbaby doctor speeds things up. Remove passwords, tokens and other secrets before pasting cases or logs.
