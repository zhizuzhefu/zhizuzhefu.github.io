安装Install

桌面端Desktop app

打开 DMG，把 requestbaby 拖进“应用程序”。桌面端自带命令行：在菜单里选“安装命令行工具”，终端里就能直接用 requestbaby 命令。Open the DMG and drag requestbaby into Applications. The app bundles the CLI: choose “Install command-line tool” from the menu and requestbaby works in your terminal.

命令行Command line

以 macOS Apple 芯片为例，其他平台换成对应的文件名：Apple silicon macOS shown; use the matching file name for other platforms:

curl -LO https://github.com/zhizuzhefu/requestbaby/releases/latest/download/requestbaby-aarch64-apple-darwin.tar.gz
tar -xzf requestbaby-aarch64-apple-darwin.tar.gz
sudo mv requestbaby /usr/local/bin/
requestbaby --version

校验下载Verify the download

curl -LO https://github.com/zhizuzhefu/requestbaby/releases/latest/download/requestbaby-aarch64-apple-darwin.tar.gz.sha256
shasum -a 256 -c requestbaby-aarch64-apple-darwin.tar.gz.sha256

升级Upgrade

命令行运行 requestbaby upgrade，会下载最新版本、校验后替换自己；加 --check 只检查不安装。桌面端启动时会检查，有新版本时状态栏会提示。Run requestbaby upgrade to download the latest version, verify it and replace itself; add --check to only check. The desktop app checks at launch and shows a notice in the status bar when a new version is out.

运行环境Requirements

  • Web 用例需要本机装有 Chrome、Edge 或 Chromium，或者连接远程浏览器。Web cases need Chrome, Edge or Chromium on the machine, or a remote browser.
  • Android 用例需要 adb，以及一台开着调试的设备或模拟器。Android cases need adb and a device or emulator with debugging enabled.
  • requestbaby doctor 会检查这些是否就绪。requestbaby doctor checks that all of this is in place.

从源码构建Build from source

需要 Rust（rustup）和 cmake，源码在 GitHub。Needs Rust (rustup) and cmake. The source is on GitHub.

装好之后After installing

几条命令就能跑出第一份结果：A few commands get you a first result:

requestbaby init myapi && cd myapi
requestbaby vars set baseUrl http://localhost:8080 -e dev
requestbaby run
requestbaby open
