儿童个人信息保护规则

最近更新 / Last updated: 2026-08-18

适用范围

即兴宇宙面向 3–8 岁儿童，在 App Store 中归入儿童类目，年龄分级 4+。本规则说明我们如何处理儿童个人信息，是隐私政策的组成部分。

监护人同意

首次启动时，App 会先用一屏说明「麦克风为什么要一直开着」「孩子的原声会不会离开这台手机」以及怎么关掉，再请监护人确认一次。确认之后不再打扰。所有会跳出 App 的操作（打开外部链接、订阅、删除全部数据）都需要先通过家长验证：四指同时按住屏幕 3 秒，再答对一道两位数以内的乘法题。

我们收集的儿童信息

  • 孩子说话时的语音。这段音频会实时上传到阿里云百炼转成文字。只在本机检测到有人开口的那几秒上传，安静时一个字节都不传；音频只用于当场转写，不留存、不用于训练。不接受这一点，就不要填写 API 密钥：App 不会发出任何网络请求，同时也听不见孩子、不出声（本 App 不使用 iOS 自带的语音识别与合成，原因见隐私政策）。
  • 对话文字。由上述识别产生，仅保存在本机。
  • 角色设定句。孩子说过的原话，逐字保存在本机。
  • 本地声学特征。用于区分「孩子/其他人」，不可还原为声音，不上传。
  • 孩子的名字（可选）。由家长自行填写，仅用于作品署名与家长端文案。不填也不影响使用。

我们不保存录音文件：App 从不把音频写进磁盘，服务器上也不留孩子的录音。我们不收集：照片、位置、通讯录、设备标识符、健康数据。

为什么需要这些

对话文字用来让角色接住孩子上一句话；角色设定句用来保证角色只由孩子的原话长出来；声学特征用来在有别人说话时不把他们的话当成孩子的指令。三者缺一，产品无法成立。

共享与传输

会离开这台手机的有两样：一是孩子说话时的那几秒语音，用于转成文字；二是当前对话的文字与角色设定，用于生成角色台词并把台词念出来。

三样都由阿里云百炼处理，请求发往 dashscope.aliyuncs.com 或 token-plan.cn-beijing.maas.aliyuncs.com，数据在境内处理。生成台词一项也可以选 Anthropic Claude（数据在境外处理）或家长自填的 OpenAI 兼容端点；听孩子说话与角色的声音只有阿里云百炼一个选项，没有本机实现。App 内「设置 → 模型服务」会明确显示这三项当前分别落在谁身上。不配置密钥时不产生任何网络请求，角色退回随包剧本，但听和说不工作。

除此之外，儿童信息不向任何第三方共享、转让或披露。我们不做定向广告，不做用户画像，不做跨 App 追踪。

监护人的权利

  • 查看。家长模式中可以看到每一天的完整逐字稿，以及每个角色的全部设定句。
  • 更正。角色设定由孩子在对话中自己修改；家长可调整全局偏好（怎么陪、不主动带起哪些话题、单次时长）。
  • 删除。「设置 → 删除全部数据」一次清空，包含声学特征，不留副本。
  • 举报。逐字稿旁提供内容举报入口。

AI 生成内容

角色的台词由大语言模型即时生成，依据是孩子说过的话。模型可能出错。App 内「设置 → AI 生成内容说明」对此有单独说明。如果哪一句让你觉得不合适，请通过逐字稿旁的举报入口告诉我们。
