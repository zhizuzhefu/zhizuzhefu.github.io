Privacy Policy / 隐私政策

即兴宇宙隐私政策

最近更新 / Last updated: 2026-08-13

简体中文

一句话说明

默认设置下，孩子说话的那几秒，原声会上传到阿里云百炼转成文字——这一条我们写在明面上，不绕弯。安静时不传，音频不留存、不用于训练，家长可以一键切回完全本机的识别。文字只存在这台手机上。我们不收集个人信息，不出售数据，不使用广告、分析或跨 App 追踪 SDK，也没有账号系统。

声音怎么处理

  • 麦克风在 App 位于前台时持续开启，这是产品的核心：孩子不用按任何按钮，也不用喊唤醒词。
  • 孩子说话时，原声会离开这台手机。默认由阿里云百炼的实时语音模型（qwen-audio-3.0-realtime-plus）转成文字，请求发往 dashscope.aliyuncs.com 或 token-plan.cn-beijing.maas.aliyuncs.com，数据在境内处理。
  • 只在有人说话时上传，安静时一个字节都不传。App 在本机先做人声检测，判定有人开口才开始上传（并补上开口前 300 毫秒，否则每句话的头会被吃掉），判定说完就停。这不是一句安慰话，是可验证的代码行为。
  • 上传的音频不留存、不用于训练。它只用于当场转写这一轮的话。App 本身从不把音频写进磁盘，任何服务器上都不保留孩子的录音文件。
  • 可以完全关掉。在「设置 → 模型服务 → 听孩子说话」里选「这台手机」，识别改用 iOS 的离线语音识别，原声一步都不出网。此时角色可能听得没那么准，但产品照常运转。
  • 麦克风开着时，房间里其他人的说话声也可能落在上传的这几秒里。我们不做说话人身份识别，也不为此单独保存任何东西。

存了什么，存在哪

  • 对话逐字稿、角色名字与设定句、剪成的作品、说出口的新词——全部保存在这台设备的本地数据库里。
  • 一组用于区分「孩子/其他人」的本地声学特征（基频与谱质心的统计量）。它不是录音，不能还原成声音，不上传，也不作身份识别。
  • 家长在设置里填的偏好（语速、时长、不主动带起的话题、孩子的名字）。
  • 换手机时这些数据不会自动迁移。我们没有云端同步。

什么会离开这台手机

两件事：孩子说话时的那几秒原声（上一节已说明），以及当前对话的文字和角色设定——后者用于生成角色的台词和把台词念出来。发送的内容里没有设备标识，也没有家长自己填写的孩子名字之外的任何身份信息。

App 把能力拆成三项，家长可以分别指定由谁来做：

  • 听孩子说话（语音转文字）——默认阿里云百炼，会上传音频；可改为「这台手机」，改用 iOS 离线识别，不出网。
  • 角色怎么接话（生成台词）——只发送文字。可选阿里云百炼、Anthropic Claude，或家长自填的任意 OpenAI 兼容端点；也可改为「这台手机」，用完全离线的本机剧本。
  • 角色的声音（把台词念出来）——只发送文字。可选阿里云百炼；也可改为「这台手机」，用 iOS 自带的语音合成。

各服务商的数据流向：

  • 阿里云百炼——请求发往 dashscope.aliyuncs.com 或 token-plan.cn-beijing.maas.aliyuncs.com，数据在境内处理。
  • Anthropic Claude——请求发往 api.anthropic.com，数据在境外处理。
  • OpenAI 兼容端点——地址由家长自己填写，数据流向取决于所填的服务商。
  • 这台手机——不出网，也不需要密钥。

App 内「设置 → 模型服务」会明确显示这三项当前分别落在谁身上。如果没有配置 API 密钥，三项全部退回本机运行，此时不产生任何网络请求，产品仍然可以完整玩下去。

API 密钥由家长自行填写，存放在这台手机的系统钥匙串里，不进 iCloud、不进备份、不写入日志，卸载 App 时一并清除。

我们不做的事

  • 不集成任何广告 SDK 或第三方行为分析 SDK。
  • 不收集设备标识符，不做跨 App 追踪，不投放个性化广告。
  • 不要求注册、不要求登录、不索取通讯录、位置、相册或健康数据。
  • 不向任何第三方出售或共享孩子的数据。

删除数据

在 App 的「设置 → 删除全部数据」中一次操作即可清空全部逐字稿、角色数据、作品与声纹特征。该操作不保留副本，不需要联系客服。删除后本机不留残留。

English

In one sentence

By default, the few seconds while your child is speaking are uploaded to Alibaba Cloud Model Studio ("Bailian") to be turned into text — we say so plainly rather than burying it. Nothing is sent while the room is quiet, the audio is not retained and not used for training, and a parent can switch recognition back to fully on-device with one setting. Text is kept only on this phone. We collect no personal information, sell no data, embed no advertising, analytics or cross-app tracking SDKs, and have no account system.

How voice is handled

  • The microphone stays on while the app is in the foreground. That is the core of the product: the child never presses anything and there is no wake word.
  • While your child speaks, their voice does leave this phone. By default it is transcribed by Alibaba Cloud Model Studio's realtime speech model (qwen-audio-3.0-realtime-plus). Requests go to dashscope.aliyuncs.com or token-plan.cn-beijing.maas.aliyuncs.com and are processed within China.
  • Audio is uploaded only while someone is speaking; while it is quiet, not one byte is sent. The app runs voice-activity detection locally and starts uploading only once it hears speech (including the 300 ms before onset, or the start of each sentence would be clipped), then stops when the speaker finishes. This is verifiable behaviour in the app's own code, not a reassurance about the server.
  • Uploaded audio is not retained and not used for training. It is used only to transcribe the turn in progress. The app never writes audio to disk, and no recording of your child is kept on any server.
  • You can turn this off entirely. In Settings → "模型服务" → "听孩子说话" choose "这台手机" and recognition switches to iOS on-device recognition, so no audio leaves the phone at all. Characters may hear your child slightly less accurately; everything else works as before.
  • While the microphone is on, other people talking in the room may fall inside those same few seconds of upload. We do not perform speaker identification and store nothing separately for this purpose.

What is stored, and where

  • Transcripts, character names and the sentences that define them, finished works, and newly spoken words — all in a local database on this device.
  • A set of local acoustic features (pitch and spectral-centroid statistics) used only to tell "the child" from "someone else". It is not a recording, cannot be turned back into sound, is never uploaded, and is not used for identification.
  • Parent preferences set in the app.
  • None of this migrates automatically to a new phone. There is no cloud sync.

What leaves this phone

Two things: the few seconds of audio while your child is speaking (described above), and the text of the current conversation plus the character definitions, used to generate character lines and to speak them aloud. No device identifiers, and no identity information beyond a child's first name if a parent entered one.

The app splits this into three capabilities, and a parent can assign each one separately:

  • "听孩子说话" (speech to text) — Alibaba Cloud Model Studio by default, which uploads audio; set it to "这台手机" for on-device recognition with no network at all.
  • "角色怎么接话" (generating dialogue) — text only. Alibaba Cloud Model Studio, Anthropic Claude, or any OpenAI-compatible endpoint a parent enters; or "这台手机" for a fully offline scripted engine.
  • "角色的声音" (speaking the lines) — text only. Alibaba Cloud Model Studio, or "这台手机" for the built-in iOS speech synthesiser.

Where data goes, per provider:

  • Alibaba Cloud Model Studio — requests go to dashscope.aliyuncs.com or token-plan.cn-beijing.maas.aliyuncs.com; processed within China.
  • Anthropic Claude — requests go to api.anthropic.com.
  • OpenAI-compatible endpoint — the address is entered by the parent, so the destination depends on that choice.
  • "这台手机" — no network, no API key.

Settings → "模型服务" always shows which provider currently handles each of the three. With no API key configured all three fall back to the device, the app makes no network requests at all, and the product remains fully playable.

API keys are entered by the parent and stored in this phone's system keychain: excluded from iCloud, excluded from backups, never written to logs, and removed when the app is uninstalled.

Deleting your data

Settings → "删除全部数据" (Delete all data) erases every transcript, character, work and voice feature in one action. No copies are retained and you do not need to contact support.
