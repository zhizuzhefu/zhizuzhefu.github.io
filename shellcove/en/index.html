Questions

Is Cloud Agent a hosted cloud service?

Your own Mac is the execution host. Shellcove provides remote access, reliable delivery, state, recovery and file access. The native Agent performs the work, using its existing account and model setup.

Which Agents can I use?

Configured clients include Codex, Grok Build, OpenCode, ZCode and DeepSeek Harness. Available capabilities are shown for each Mac. DeepSeek uses its official Desktop Gateway; Desktop-owned live questions still require the native client.

Does work continue after I leave the app?

Accepted work continues on the Mac while it stays online and awake. Reconnect to read results. Live interaction needs a connection between the phone and the Mac.

Will an upgrade require new Mac permissions?

Production packages keep the same Bundle ID, Team ID, Developer ID requirement and installed path to retain existing grants. Existing pairings continue; explicitly creating a new pairing code migrates legacy shared credentials.
