Privacy and connections

No Shellcove cloud account, ads or analytics. Paired connections use pinned TLS and client authentication. Relays forward encrypted content and may process connection metadata. Model providers handle submitted inputs under their own terms.

Questions

Do I need another model subscription?

Shellcove does not sell model access. Use a supported native Agent with its own account or plan. Current qualified model integration is Zhipu through official ZCode CLI; existing external ZCode desktop sessions are history-only.

Which versions work together?

The 1.6 beta requires the 1.6 Mac companion. It cannot connect to protocol 1.5. The public download may still be the previous release; use the matching Mac package supplied for this beta.

Is Screen Recording required for AI tasks?

No. Screen Recording is for Remote Desktop; Accessibility is for device input and Window Text. Production upgrades preserve the installed path and Developer ID signing identity to retain compatible existing grants.

Can tasks run while I am away?

Keep the execution computer online and awake, and the mobile app in the foreground for interaction. Direct LAN connections are preferred; embedded Tailcat provides Internet connectivity and encrypted relay fallback without a Shellcove account.
