No account

Pair your own Macs, one at a time

Shellcove · Cloud Agent needs no cloud account. Scan each Mac’s QR to pin its certificate and receive a phone credential. Macs do not pair with each other. Choose one execution Mac for each task.

Steps

  1. Install the matching Mac app on macOS 13 or newer. Keep the existing production path and signing identity when upgrading. Native Agents retain their own authorization; Accessibility and Screen Recording serve the separate device tools.
  2. For a new phone, generate a pairing code in Mac settings and scan it from Computers on iOS 16 or newer. Allow Local Network if asked. An explicit legacy-pairing migration requires old phones to scan again; a normal in-place upgrade preserves pairings.
  3. Stay on Automatic if the Mac has no public address. Tailcat tries a hole-punch, then an encrypted relay over TCP.
  4. Choose Direct if you only want LAN or your own VPN. That choice does not start Tailcat.

Once connected, choose a Mac and Agent in Tasks. For device tools, see Remote Desktop.

Questions

Do I have to install Tailscale?

No. Wi-Fi on the same network is fastest. Automatic mode can use built-in Tailcat without a public IP, port forward, or Tailscale account. Direct-only mode does not start Tailcat. A VPN you already run remains a direct path.

What does the relay learn?

It cannot read the desktop, window text, clipboard, or keystrokes. Those stay inside the certificate pinned at pairing. The relay forwards ciphertext and may see that a connection exists, plus timing and size.
