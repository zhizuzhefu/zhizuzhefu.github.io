Mac + iPhone · 不需要账号Mac + iPhone · No account

扫码配对，连接自己的 MacPair your phone with your own Mac

Shellcove · Cloud Agent 无需云端账号。iPhone 或 iPad 分别扫描每台 Mac 的配对码，核对证书指纹并取得该手机的连接凭据。Mac 之间不互相配对；每个任务在你选择的一台 Mac 完成。Shellcove · Cloud Agent needs no cloud account. Scan each Mac's QR to pin its certificate and receive a phone credential. Macs do not pair with each other. Choose one execution Mac for each task.

配对前，先确认两端版本Before pairing, match the versions

iPhone / iPad 与 Mac 需要配套版本，并已在 Mac 上配置可用的原生 Agent。查看下载与版本选择。Use matching phone and Mac versions, with a configured native Agent on the Mac. Check downloads and versions.

配对步骤Steps

  1. Mac 需要 macOS 13 或更新版本。从 Shellcove 的 Mac 安装包打开 App。
  2. 在 Mac 设置中确认原生 Agent 可用。辅助功能与屏幕录制用于另列的设备工具，原生 Agent 保留自己的授权。
  3. 新手机接入时，在 Mac 设置里生成配对码，再从 iOS「电脑」页添加并扫描。若提示迁移旧共享配对，原设备需要重新扫码；普通原位升级不主动触发迁移。
  4. 如果系统询问本地网络权限，允许 Shellcove 访问。
  5. 同一 Wi-Fi 会最快连上。不在同一网络时，保持自动模式，内置 Tailcat 会尝试打洞，不行再走加密中继。
  1. Install the matching Mac app on macOS 13 or newer. Keep the existing production path and signing identity when upgrading. Native Agents retain their own authorization; Accessibility and Screen Recording serve the separate device tools.
  2. For a new phone, generate a pairing code in Mac settings and scan it from Computers on iOS 16 or newer. Allow Local Network if asked. An explicit legacy-pairing migration requires old phones to scan again; a normal in-place upgrade preserves pairings.
  3. Stay on Automatic if the Mac has no public address. Tailcat tries a hole-punch, then an encrypted relay over TCP.
  4. Choose Direct if you only want LAN or your own VPN. That choice does not start Tailcat.

三条路怎么选Choosing a path

  • 局域网或你自己的 VPN：直连，远程桌面优先走 UDP/DTLS。LAN or your own VPN: direct. Remote Desktop prefers UDP/DTLS.
  • 自动模式：也会启动 Tailcat。这一路使用 TCP，不需要另装 Tailscale。Automatic: also starts Tailcat. This path uses TCP; no separate Tailscale install.
  • 只选直连：不会启动 Tailcat。设置里仍可手动添加一台中继的主机和端口。Direct-only: never starts Tailcat. A manual relay host and port can still be added in settings.

连上后，在「任务」中选择 Mac 和 Agent；需要设备工具时，见 远程桌面。Once connected, choose a Mac and Agent in Tasks. For device tools, see Remote Desktop.

常见问题Questions

必须安装 Tailscale 吗？Do I have to install Tailscale?

不用。同一 Wi-Fi 最快。不在同一网络时，自动模式会使用内置 Tailcat，不需要公网 IP、端口转发或 Tailscale 账号。只选直连时不会启动 Tailcat。你自己的 VPN 仍然可以当作直连路径。No. Wi-Fi on the same network is fastest. Automatic mode can use built-in Tailcat without a public IP, port forward, or Tailscale account. Direct-only mode does not start Tailcat. A VPN you already run remains a direct path.

配对之后中继能看到我的桌面吗？What does the relay learn?

不能读取桌面、窗口文本、剪贴板或按键。连接使用配对时钉住的 TLS 证书。中继只转发密文，但可能看到连接是否发生、时间和流量大小。It cannot read the desktop, window text, clipboard, or keystrokes. Those stay inside the certificate pinned at pairing. The relay forwards ciphertext and may see that a connection exists, plus timing and size.

连接不上时，按这个顺序检查If you cannot connect, check these first

  1. 确认 Mac 在线、唤醒，并且 Shellcove 正在运行。Check that the Mac is online, awake and running Shellcove.
  2. 在 iOS 设置中允许 Shellcove 访问本地网络；扫描二维码时允许相机访问。Allow Shellcove Local Network access in iOS settings, and Camera access when scanning the QR.
  3. 先在同一 Wi-Fi 下确认配对与连接。只用局域网或自己的 VPN 时选择直连，其他情况可尝试自动模式；实际可用性取决于现场网络。First verify pairing on the same Wi-Fi. Use Direct for a LAN or your own VPN, or try Automatic otherwise. Availability depends on the actual network.
  4. 若 Mac 已撤销这部手机，使用新配对码重新添加。普通升级无需重新配对；不要为排查连接问题重置系统权限。If the Mac revoked this phone, pair again with a new code. Normal upgrades do not require pairing again; do not reset system permissions as a connection fix.
