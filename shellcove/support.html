开始一个任务Start a task

  1. 在 Mac 设置中确认已安装的原生 Agent 可用，沿用其登录、模型选择与授权。
  2. 新手机接入时，在 Mac 设置中生成配对码，从 iOS「电脑」页添加并扫描。多台 Mac 分别添加，不需要 Mac 之间建立信任。
  3. 在「任务」中选择 Mac 与 Agent，新建独立会话或继续已有原生会话；项目和任务只是可选组织方式。
  4. 一个任务全程在一台 Mac 完成。保持该 Mac 在线且唤醒；离开手机 App 后，已接收的工作仍会继续。
  1. Check the native Agent in Mac settings. Keep its existing login, model choice and authorization.
  2. For a new phone, generate a pairing QR in Mac settings and scan it from Computers on iOS. Add each Mac separately; Macs need no trust relationship with one another.
  3. Choose a Mac and Agent in Tasks. Create a standalone conversation or continue an existing native conversation. Projects and Tasks are optional organization.
  4. Each task stays on one Mac. Keep that Mac online and awake. Accepted work continues when you leave the phone app.

材料与成果Materials and results

会话中使用「添加材料」送入文档或照片，每次最多 4 份，每份不超过 10 MiB。保存成果时取回完整原件，核对大小、版本与摘要。文档可以交给其他 App 打开；Shellcove 保留图片预览、视频播放和普通文本显示，不提供 PDF、表格阅读器或 ZIP 专项功能。

Use Add material in a conversation to upload documents or photos: up to four files, 10 MiB each. Save complete originals with size, version and digest checks, or open documents in another app. Image previews, video playback and ordinary text display remain available. Shellcove does not add a PDF/spreadsheet reader or a dedicated ZIP workflow.

等待、补充与核对Waiting, input and receipts

  • 原生回合结束表示当前执行结束，用户任务是否完成仍由你决定。
  • 输入可排到下一回合；尚未执行时可单条撤回。立即补充与停止按原生 Agent 实际能力开放，停止需原生确认。
  • 提交结果未知时，先核对同一次提交的回执，不重新发送。
  • 原生业务问题有有效答复入口时可从手机回答。DeepSeek 通过官方 Desktop Gateway 连接，仍由 Desktop 持有的当前问题需要在那里答复。
  • 手机离线时可读已缓存内容；实时状态、发送与下载需要重新连接。
  • An idle native turn means that turn ended. You still decide when the user task is complete.
  • Queue the next input and withdraw individual items before execution. Immediate input and stop depend on native capabilities; stop needs native confirmation.
  • When submission is uncertain, check its original receipt instead of sending again.
  • Answer native business questions from the phone when a valid native handle is available. DeepSeek connects through the official Desktop Gateway; a live question still owned by Desktop must be answered there.
  • Cached content remains readable offline. Live state, sending and downloads need a connection.

配对与单设备撤销Pairing and phone revocation

新手机使用独立凭据。手机丢失时，在 Mac 的已配对设备设置中撤销该身份，其连接关闭、旧凭据被拒绝；其他手机和已经接收的任务继续。

旧共享凭据无法区分各部手机。只有主动生成新的独立配对码并接受界面中的迁移提示，才会停用旧共享凭据；原设备届时需要重新扫码。移除配对、归档 Shellcove 任务都不删除原生 Agent 历史。

New phones use independent credentials. Revoke a lost phone in the Mac’s paired-device settings to close its connections and reject its old credentials. Other phones and accepted tasks continue.

Legacy shared credentials cannot distinguish phones. They retire only when you explicitly generate a new independent pairing code through the migration notice; old phones must then scan again. Removing a pairing or archiving a Shellcove task does not delete native Agent history.

连接与设备工具Connection and device tools

同一 Wi-Fi 或自己的 VPN 可直连；自动模式可使用内置 Tailcat 和加密中继，无需 Tailscale 账号。不同网络的实际可用性仍取决于现场网络条件。详见配对说明。

远程桌面、窗口文本、键盘鼠标与剪贴板在「电脑 → 设备详情」。辅助功能和屏幕录制用于这些设备工具，与原生 Agent 授权分开。实时控制需要手机前台连接，详见设备工具说明。

Use the same Wi-Fi or your own VPN for direct access. Automatic mode can use built-in Tailcat and an encrypted relay without a Tailscale account. Cross-network availability depends on the actual network conditions. See pairing.

Remote Desktop, Window Text, keyboard, mouse and clipboard remain in Computers → device details. Accessibility and Screen Recording serve these device tools, separately from native Agent authorization. Live control needs a foreground phone connection. See device tools.
