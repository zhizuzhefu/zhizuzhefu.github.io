开始第一个任务Start your first task

  1. 在 Mac 上打开 Shellcove，确认设置里的原生 Agent 可用，沿用其登录、模型和授权。Open Shellcove on the Mac and check that its native Agent is available in settings. Keep the Agent’s existing login, model and authorization.
  2. 新手机接入时，在 Mac 设置中生成配对码，从 iOS「电脑」页添加并扫描。多台 Mac 分别添加。查看配对步骤。For a new phone, generate a pairing QR in Mac settings, then add and scan it in Computers on iOS. Pair each Mac separately. See pairing steps.
  3. 进入「任务」，继续已有原生会话，或选择「新建独立会话」。先写想完成什么，再按需调整电脑、Agent 和目录。Open Tasks to continue an existing native conversation or create a standalone one. Start with your goal, then adjust the Mac, Agent or directory if needed.
  4. 按需添加材料并发送。保持执行 Mac 在线、唤醒；离开手机后，已接收的工作继续。回来在「材料与文件」取回结果。Add materials as needed and send. Keep the execution Mac online and awake; accepted work continues after you leave the phone. Return to Materials & Files to retrieve results.

项目和任务用于整理长期工作，可以之后再建；直接开一个独立会话也能开始。Projects and Tasks help organize longer work. You can add them later or simply start a standalone conversation.

回来后，先看需要你处理的事Return to what needs your attention

电脑连接与 Agent 执行是两件事。断线时显示的是上次已知状态，不能据此认定任务已经停止或完成。The Mac connection and Agent execution are separate. Offline state is the last known observation; it does not confirm that a task stopped or finished.

  • 需要答复：打开原生问题，按可用入口回答；必须回原生客户端处理时，会明确说明。Needs an answer: open the original question and use its supported answer action. A native-client-only question is identified as such.
  • 结果待核对：先检查同一次提交的回执与原消息，避免重复执行。Needs checking: check the original submission receipt and messages before sending again.
  • 有新回复：点击回到原内容。已读记录只保存在当前设备。New reply: open the original content. Read state is local to this device.
  • 执行中：查看最近收到的真实回复与工具记录；原生一轮结束由你判断是否达成整个目标。Running: read actual replies and tool records as received. An ended native turn does not decide whether your whole goal is complete.

执行中可以按能力立即补充，或排到下一回合。尚未提交的排队要求可以单条撤回；停止操作要等原生 Agent 确认。During execution, add immediate input where supported or queue it for the next turn. Withdraw individual queued instructions before submission. Stop waits for the native Agent’s acknowledgement.

搜索记录，复用常用要求Search records and reuse instructions

会话中的搜索入口可查找本设备已加载的文字、工具输出和文件名，并定位原段落。更早记录由你按需加载；Mac 也可以用 ⌘F。离线可搜索已经缓存的内容。Conversation search finds loaded text, tool output and filenames on this device and takes you to the original passage. Load earlier history when needed; use ⌘F on Mac. Cached content remains searchable offline.

在输入区旁的「常用要求」保存当前草稿，或新建、编辑具名文字。使用时填入或追加到草稿，检查后再发送。导入、导出只包含纯文字，不包含材料、引用、模型或权限，也不会自动跨设备同步。Use Saved instructions beside the composer to save a draft or create and edit named text. Fill or append it to a draft, check it, then send. Import and export contain only text, without materials, references, models or permissions. There is no automatic cross-device sync.

上传材料，取回完整文件Send materials and save complete files

「材料与文件」汇总本会话已加载消息中的真实文件引用和材料，保留来源消息及版本。没看到较早文件时，先加载更早记录。Materials & Files gathers genuine references and materials from loaded messages in this conversation, retaining the source message and version. Load earlier history if an older file is missing.

每次最多添加 4 份材料，每份不超过 10 MiB。看清上传中、待发送、已提交或待核对状态；上传完成不代表已经交给 Agent。保存成果时核对完整原件，可保存副本或交其他 App 打开。Add up to four materials, 10 MiB each. Check whether they are uploading, ready to send, submitted or awaiting verification; an uploaded file has not necessarily been sent to the Agent. Save a verified original or open it in another app.

图片、视频可预览，普通文本可显示。PDF、表格等文档交给适合的 App 处理。Preview images and videos or display ordinary text. Open PDFs, spreadsheets and other documents in an appropriate app.

原生 Agent 接入要求Native Agent requirements

支持接入已配置的 Codex、Grok Build、OpenCode、ZCode 与 DeepSeek Harness。可用版本、状态和能力以 Mac 设置为准；Shellcove 不替你切换模型、自动升级或重启这些客户端。Connect configured Codex, Grok Build, OpenCode, ZCode and DeepSeek Harness clients. Check versions, status and capabilities in Mac settings. Shellcove does not switch models, automatically upgrade or restart these clients.

DeepSeek 使用官方 Desktop Gateway，仍由 Desktop 持有的当前问题需要在那里回答。外部 ZCode Desktop 会话只读，执行使用受管理的 CLI 会话。登录、额度、模型与工具授权继续由原生客户端管理。DeepSeek uses its official Desktop Gateway; a live question still owned by Desktop must be answered there. External ZCode Desktop conversations are read-only; managed CLI conversations support execution. Native clients continue to manage sign-in, quota, models and tool authorization.

遇到问题，先做这一步When something goes wrong, start here

连不上 MacCannot connect to the Mac

确认 Mac 在线、唤醒且 Shellcove 正在运行；允许 iOS 本地网络访问。同一 Wi-Fi 下先确认连接，再检查所用的直连或自动模式。查看连接排查。Check that the Mac is online, awake and running Shellcove, and allow iOS Local Network access. First try the same Wi-Fi, then check Direct or Automatic mode. Troubleshoot the connection.

Agent 提示登录、额度或服务问题The Agent reports sign-in, quota or service trouble

按页面提示，在这台 Mac 的原生客户端处理对应账号或服务，再重新检查状态。电脑连接正常不代表 Agent 的登录或额度一定可用。Follow the displayed next step in the native client on that Mac, then check status again. A connected Mac does not confirm that the Agent’s account or quota is available.

发送后不确定是否执行Not sure whether an instruction ran

先核对这次提交的回执，再看原生记录。结果未知时不要重复发送；也不要换一台电脑重做同一条要求。Check this submission’s receipt and native history first. Do not resend an uncertain instruction or move it to another Mac to repeat it.

文件保存失败或版本变化A file cannot be saved or its version changed

检查 Mac 连接和文件原始来源，再按界面重试。文件变化时重新读取当前可用版本；不要把正文里的任意路径当作可下载文件。Check the Mac connection and original file source, then use the displayed retry action. Read an available version again if the file changed; an arbitrary path in message text is not a download reference.

仍有问题？提交反馈时附上双方版本、Mac 上的 Agent 名称、看到的状态和复现步骤，避免包含凭据或私人材料。Still stuck? Send feedback with both app versions, the Agent name, visible state and reproduction steps. Omit credentials and private materials.

These tools need a live connection and are separate from Agent conversations. See device tools.
