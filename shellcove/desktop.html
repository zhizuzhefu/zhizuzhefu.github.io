视频流 · 窗口文本 · 键盘Video · text · keyboard

在手机上看 Mac，并把字送到焦点窗口Drive the desktop, or read the window as text

配对完成后，从「电脑 → 设备详情」进入「远程桌面」或「窗口文本」。前者看画面并触控，后者读取焦点窗口的真实文字。Agent 会话在「任务」中使用，设备控制不放在会话操作里。还没配对的话，先看 如何配对。Open Remote Desktop or Window Text from Computers → device details. Remote Desktop shows video; Window Text reads the focused window's characters without OCR. Agent conversations remain in Tasks, separate from device control. If you have not paired yet, start with pairing.

画面和文字Picture and text

  • 点按或拖动移动 Mac 光标，捏合放大，双指滚动，长按后拖拽。Tap or drag to move the Mac cursor, pinch to zoom, two-finger scroll, and long-press to drag.
  • 键盘面板里可以单击、右键、双击和长按，也可以切到另一块显示器。The keyboard panel offers click, right-click, double-click and long-press, and can switch to another display.
  • 窗口文本走辅助功能，读取字符，不用 OCR，并保留终端换行。Window Text uses Accessibility to read real characters — no OCR — and keeps terminal line breaks.
  • 底部「输入到 Mac」打开系统键盘、听写或你安装的输入法。Shellcove 只接收最终文本，不申请麦克风权限。Input to Mac opens the system keyboard, Dictation, or a third-party input method. Shellcove receives only the finished text and does not ask for the microphone.
  • 剪贴板会在已配对设备之间同步。设备工具中也有常用快捷键，完整键盘在远程桌面里打开。Clipboard changes mirror between paired devices. Device-tool shortcuts cover common terminal keys; the full keyboard opens inside Remote Desktop.

网络弱的时候When the link is weak

直连优先走 UDP/DTLS。Tailcat 和手动中继走 TCP 视频。画面变差时，Shellcove 先保清晰度，再降低帧率和码率。弱网不是无限流畅的承诺。On a direct LAN path, video prefers UDP. Tailcat and a manual relay use TCP. A weak link keeps clarity first and then lowers frame rate. That is a recovery behavior, not a promise of a smooth picture.

常见问题Questions

远程桌面是一连串截图吗？Is Remote Desktop a burst of screenshots?

不是。Mac 用屏幕采集和硬件编码把桌面做成视频，iPhone 再硬件解码。点按、拖动、捏合和双指滚动都作用在这块画面上。No. The Mac captures and hardware-encodes a video stream, and the iPhone decodes it. Taps, drags, pinches, and two-finger scrolls act on that picture.

手机锁屏之后还能继续控 Mac 吗？Does control continue after I leave the app?

远程桌面与实时控制需要手机前台连接，回到前台后会重连。已经由 Mac 接收的 Agent 任务仍会继续，前提是执行 Mac 在线且唤醒。Live Remote Desktop and control need a foreground connection. Returning reconnects. Accepted Agent tasks continue on the execution Mac while it stays online and awake.
