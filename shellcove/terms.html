服务说明What Shellcove is

Shellcove · Cloud Agent 让 iPhone / iPad 连接自己的多台 Mac，提交任务、继续原生 Agent 会话、查看执行状态、上传材料和保存完整成果。一个任务在一台 Mac 完成；原生 Agent 负责推理、工具、模型配置和会话，Shellcove 负责已配对设备之间的访问、可靠送达、回执与恢复。设备工具另提供远程桌面、窗口文本、键盘鼠标和剪贴板。连接使用 TLS 与客户端认证，必要时可经加密中继。Shellcove 不提供托管的模型服务、云端文件存储或账号；使用的原生 Agent、模型服务及其账号或套餐适用各自条款。本服务不提供金融、医疗、法律等专业服务。

Shellcove · Cloud Agent connects iPhone / iPad to your own Macs to submit tasks, continue native Agent conversations, inspect execution, upload materials and save original results. Each task runs on one Mac. The native Agent owns reasoning, tools, model settings and conversations; Shellcove handles access, delivery receipts and recovery between paired devices. Separate device tools provide Remote Desktop, Window Text, keyboard, mouse and clipboard access. Connections use TLS and client authentication, with an encrypted relay when needed. Shellcove provides no hosted model service, cloud file store or account. Native Agents, model services and their accounts or plans remain subject to their own terms. Shellcove provides no financial, medical, legal or other professional services.
