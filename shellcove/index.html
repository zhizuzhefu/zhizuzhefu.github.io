开始前，你可能想知道Before you start

Cloud Agent 的工作在哪里运行？Where does Cloud Agent run the work?

在你自己的 Mac 上。Shellcove 是 iPhone、iPad 与 Mac 之间的 Agent 任务入口，提供访问、状态、可靠送达和文件取回。你需要已有可用的原生 Agent。On your own Mac. Shellcove is an Agent task terminal across iPhone, iPad and Mac, providing access, status, reliable delivery and file retrieval. You need a configured native Agent.

关掉手机 App，任务会停止吗？Does leaving the phone app stop a task?

不会因为手机断线而停止已接收的工作。Mac 及原生 Agent 需要保持运行，Mac 也需要在线、唤醒。回来重新连接后，可以继续阅读进展和结果。A phone disconnect does not stop accepted work. Keep the Mac and native Agent running, and the Mac online and awake. Reconnect to read progress and results.

原有会话和模型需要重新配置吗？Do I need to set up my conversations or model again?

沿用原生客户端的登录、模型和会话。能否继续某个已有会话，以 Agent 提供的能力和当前归属为准；查看支持范围。Native clients retain their login, model settings and conversations. Whether an existing conversation can continue depends on the Agent’s capabilities and ownership. See the supported scope.

文件可以保存到手机吗？Can I save files to my phone?

可以从真实文件引用取回不超过 10 MiB 的完整原件，保存副本或用其他 App 打开。图片和视频支持预览；文档处理由你选用的 App 完成。Retrieve complete originals up to 10 MiB from real file references, then save a copy or open them in another app. Images and videos can be previewed; use your chosen app for documents.

多台 Mac 会自动接力完成任务吗？Do several Macs automatically share a task?

你可以连接多台 Mac，分别安排不同工作。每个任务固定在一台 Mac，相关原生会话也留在那里；不会自动拆分或迁移到另一台电脑。Connect several Macs and give them separate work. Each task and its native conversations stay on one Mac; Shellcove does not automatically split or migrate a task.

我的任务和文件会发到哪里？Where do my tasks and files go?

内容在已配对设备之间传输；你提交给原生 Agent 的内容会按其配置交由模型服务商处理。Shellcove 没有广告或使用统计。必要时的中继转发加密内容，可能处理连接元数据。阅读隐私说明。Content moves between paired devices. Native Agents may send submitted content to their configured model providers. Shellcove has no ads or usage analytics. Relays forward encrypted content and may process connection metadata.
