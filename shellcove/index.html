Shellcove · Cloud Agent · 1.6 内测

把你的 Mac，变成私有 Cloud Agent。

用手机交代工作、查看进展、继续原会话并取回完整成果。每个任务固定在一台 Mac 上执行，不同任务可以分别在不同 Mac 并行。

原生 Agent一台 Mac 完成一个任务完整原件

安装与开始使用

1.6 通过 TestFlight 内测，请使用同版本 Mac 配套客户端。

任务在自己的 Mac 上运行

原生 Agent 负责推理、工具和原生会话。Mac 保持在线、唤醒时，离开手机 App 后已接收工作继续执行。

继续原会话，核对真实状态

查看原始回复、工具活动、排队输入和待核对回执。停止等待原生确认；未知提交不自动重发。原生开放答复入口时，可在手机回答业务问题。

送入材料，保存完整成果

每次最多上传 4 份材料，每份 10 MiB。核对原件版本、大小和摘要，保存文件或交其他 App 打开；图片和视频保留预览。

连接多台 Mac，各自执行

iOS 分别连接每台已配对 Mac，各连接状态独立。每部手机可单独撤销，Mac 不互联、不转发任务。

你的设备，你的原生 Agent

无需 Shellcove 云账号、广告或统计。登录、模型与工具由原生 Agent 管理。配对连接采用 TLS 钉扎与客户端认证；模型服务商按原生配置处理提交的内容，中继转发加密内容并可能处理连接元数据。

常见问题

Cloud Agent 是托管云服务吗？

执行节点是你自己的 Mac。Shellcove 提供远程访问、可靠送达、状态、恢复与交付；原生 Agent 负责实际工作，不需要新的 Shellcove 模型订阅。

可以连接哪些 Agent？

支持已配置的 Codex、Grok Build、OpenCode、ZCode 与 DeepSeek Harness，具体能力以设备状态为准。DeepSeek 使用官方 Desktop Gateway；当前由 Desktop 持有的问题需在原生客户端答复。

手机离开后任务会继续吗？

已接收的任务由 Mac 继续，Mac 需保持在线、唤醒。回来后重新连接即可阅读结果；实时交互需要手机与 Mac 保持连接。

升级需要重新授权吗？

正式 Mac 包沿用同一 Bundle ID、Team ID、Developer ID 签名要求与安装路径，以保留现有辅助功能和录屏授权。现有配对继续可用，主动生成新配对码才迁移旧共享配对。
