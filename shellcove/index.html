电脑里的 AI 任务，手机上接着做。

Shellcove 连接你已配对电脑上的原生 Agent。新建需求、继续原会话、查看结果和保存文件，让调研、写作、文件整理与编程都能跨设备进行。

原生会话跨设备协同原始文件

安装与开始使用

1.6 当前通过 TestFlight 内测。手机与 Mac 需使用同版本配套客户端。

任务，始终沿用原上下文。

在「任务」页搜索会话、按电脑筛选、继续交流并查看流式回复。停止请求等待原生确认，断线后先核对回执，不自动重发。

电脑，用你自己的名字。

为每台电脑设置名称和可选别名。扫码配对一次，任务仍由所属电脑执行，Agent、工具和文件留在原处。

结果，看得清，也带得走。

预览文本、Markdown 和图片，保存单个最多 1 MiB 的原始文件。草稿与已缓存内容保存在设备上，断线时仍可阅读。

设备工具，需要时再打开。

远程桌面、窗口文本、键盘鼠标和剪贴板位于「电脑 → 设备详情」，不会挤进日常任务对话。

隐私与连接

无 Shellcove 云账号、广告或统计。配对连接采用 TLS 证书钉扎与客户端认证；中继转发加密内容并可能处理连接元数据。你发送给模型的内容由对应服务商按其条款处理。

常见问题

需要订阅新的模型服务吗？

Shellcove 不提供模型订阅。你使用原有原生 Agent 及其账号与套餐；当前真实模型验收为官方 ZCode CLI 的智谱接入。外部已有 ZCode 桌面会话目前仅支持查看历史。

手机和 Mac 要使用什么版本？

1.6 内测需搭配 1.6 Mac 客户端，不能连接旧的 1.5 协议。当前公开下载可能仍是上一正式版，内测请使用随版本提供的 Mac 安装包。

必须开屏幕录制权限吗？

阅读和继续 Agent 会话不要求屏幕录制。屏幕录制用于远程桌面，辅助功能用于设备输入和窗口文本。正式升级保持原安装路径及 Developer ID 签名身份，避免因切换开发版而重新授权。

离开电脑后还能继续吗？

执行电脑须保持在线、唤醒，手机交互须保持 App 在前台。优先使用局域网直连，内置 Tailcat 提供互联网连接与加密中继；不需要 Shellcove 云账号。
