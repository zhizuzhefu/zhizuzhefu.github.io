常见问题Questions

Cloud Agent 是托管云服务吗？Is Cloud Agent a hosted cloud service?

执行节点是你自己的 Mac。Shellcove 提供远程访问、可靠送达、状态、恢复与交付；原生 Agent 负责实际工作，不需要新的 Shellcove 模型订阅。Your own Mac is the execution host. Shellcove provides remote access, reliable delivery, state, recovery and file access. The native Agent performs the work, using its existing account and model setup.

可以连接哪些 Agent？Which Agents can I use?

支持已配置的 Codex、Grok Build、OpenCode、ZCode 与 DeepSeek Harness，具体能力以设备状态为准。DeepSeek 使用官方 Desktop Gateway；当前由 Desktop 持有的问题需在原生客户端答复。Configured clients include Codex, Grok Build, OpenCode, ZCode and DeepSeek Harness. Available capabilities are shown for each Mac. DeepSeek uses its official Desktop Gateway; Desktop-owned live questions still require the native client.

手机离开后任务会继续吗？Does work continue after I leave the app?

已接收的任务由 Mac 继续，Mac 需保持在线、唤醒。回来后重新连接即可阅读结果；实时交互需要手机与 Mac 保持连接。Accepted work continues on the Mac while it stays online and awake. Reconnect to read results. Live interaction needs a connection between the phone and the Mac.

升级需要重新授权吗？Will an upgrade require new Mac permissions?

正式 Mac 包沿用同一 Bundle ID、Team ID、Developer ID 签名要求与安装路径，以保留现有辅助功能和录屏授权。现有配对继续可用，主动生成新配对码才迁移旧共享配对。Production packages keep the same Bundle ID, Team ID, Developer ID requirement and installed path to retain existing grants. Existing pairings continue; explicitly creating a new pairing code migrates legacy shared credentials.
