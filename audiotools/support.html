FAQ / 常见问题

为什么文件无法导入？ / Why can't I import a file?

请先确认文件格式是否受支持（如 MP3、WAV、M4A 等常见音频格式均可导入），并确保文件大小未超过 500 MB。如果文件来自其他 App，请尝试通过"共享"菜单将文件发送到音频随转。若问题仍然存在，请重启 App 后再试。 / First, check that your file is in a supported format — common audio formats like MP3, WAV, and M4A can all be imported. Also ensure the file is under 500 MB. If the file is from another app, try using the Share menu to send it to AudioTools. If the issue persists, restart the app and try again.

为什么 WiFi 传输无法访问？ / Why can't I access WiFi Transfer?

请确认你的电脑和 iOS 设备连接到同一个 WiFi 网络，然后在浏览器中输入 App 内显示的本地地址（如 http://192.168.x.x:8080）。如果仍无法连接，请检查路由器是否开启了"客户端隔离"功能，或尝试关闭 VPN 后重试。 / Make sure your computer and iOS device are connected to the same Wi-Fi network, then enter the local address shown in the app (e.g., http://192.168.x.x:8080) into your browser. If it still doesn't connect, check whether your router has "client isolation" enabled, or try disabling any VPN and retrying.

为什么没有收到通知？ / Why didn't I receive notifications?

请前往"设置 > 通知 > 音频随转"，确认通知权限已开启。如果你使用了专注模式，请确保音频随转未被屏蔽。即使关闭通知，所有核心转换功能仍可正常使用，不受影响。 / Go to Settings > Notifications > AudioTools and make sure notifications are enabled. If you're using Focus mode, check that AudioTools is not blocked. Rest assured that all core conversion features work perfectly even with notifications turned off.

支持哪些输出格式？ / What output formats are supported?

音频随转可以导出 M4A、AAC、MP3、WAV、CAF（Apple Lossless）、Ogg + Opus 以及 MP4。免费版最高 192 kbps，WAV 和 Apple Lossless 属于一次买断的 Pro。MP3 兼容性最广，M4A 在苹果设备上更合适。 / AudioTools can export M4A, AAC, MP3, WAV, CAF (Apple Lossless), Ogg + Opus, and MP4. The free version stops at 192 kbps. WAV and Apple Lossless belong to the one-time Pro purchase. MP3 is the most compatible; M4A fits Apple devices well.

怎么把音频设成手机铃声？ / How do I set audio as my ringtone?

在转换结果页点「设为手机铃声」，App 会导出一段不超过 30 秒的铃声文件（.m4r）。由于 iOS 不允许第三方 App 直接安装铃声，请按照引导用苹果「库乐队 / GarageBand」完成：1) 点「拷贝到库乐队」；2) 在库乐队中长按该音频并选择「共享」；3) 选择「电话铃声」并导出；4) 打开「设置 → 声音与触感 → 电话铃声」即可选用。如未安装库乐队，可在 App Store 免费下载。 / On the conversion result screen, tap “Set as ringtone”. The app exports a ringtone file (.m4r) of up to 30 seconds. Because iOS does not allow third-party apps to install ringtones directly, follow the in-app guide using Apple GarageBand: 1) tap “Copy to GarageBand”; 2) long-press the audio in GarageBand and choose “Share”; 3) select “Ringtone” and export; 4) open Settings → Sounds & Haptics → Ringtone to select it. GarageBand is a free download on the App Store.

这个 App 收费吗？有广告吗？ / Is the app paid? Are there ads?

可以免费下载，没有广告，也不是订阅。免费版每天完整转换 3 次，最高 192 kbps，一次一个文件，铃声每月 1 次，结果保留 7 天。Pro 一次买断，价格 1.99 美元：不限次数，最高 320 kbps，可导出 WAV 和 Apple Lossless，铃声不限次数，并支持批量转换。 / The download is free. There are no ads and no subscription. The free version allows 3 full conversions a day, up to 192 kbps, one file at a time, one ringtone a month, kept for 7 days. Pro is a one-time $1.99 purchase: unlimited conversions, up to 320 kbps, WAV and Apple Lossless, unlimited ringtones, and batch conversion.
