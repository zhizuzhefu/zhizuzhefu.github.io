让 AI 助手操作你正在用的 Chrome

Open WebBridge 是免费的开源 Chrome 扩展。AI 助手可以使用你已有的浏览器会话来读取网页、点击、填表和截图。

安装 Chrome 扩展 安装配套程序

桌面版 Chrome · 支持 macOS、Linux 和 Windows · 无需注册账号

试跑一条浏览器命令

open-webbridge call navigate --session demo --args '{"url":"https://example.org","newTab":true}'
open-webbridge call snapshot --session demo

AI 助手可以在 Chrome 里做什么？

使用已登录的会话

从你已经登录的系统读取看板、导出报表，浏览器继续使用你现有的配置。

读取和操作网页

获取网页的无障碍结构，点击控件、填写字段，或保存截图和 PDF。

在网页上标注

把评论直接附到网页元素上，AI 助手就能找到你希望它检查的控件。

安装 Open WebBridge

扩展和配套程序都运行在打开 Chrome 的同一台电脑上。

  1. 添加 Chrome 扩展

    用桌面版 Chrome 打开 Chrome 应用商店官方页面，点击添加至 Chrome。

  2. 安装配套程序

    在 macOS 或 Linux 的终端运行安装脚本。

    curl -fsSL https://raw.githubusercontent.com/zhizuzhefu/open-webbridge/main/scripts/install.sh | bash

    在 Windows 上下载对应架构的文件，然后按 PowerShell 安装步骤运行。

    • Windows x64
    • Windows ARM64
    • 全部下载

  3. 连接 Chrome

    运行 open-webbridge url。把生成的连接地址粘贴到扩展弹窗，点击 Connect。

  4. 确认连接并运行第一条命令

    运行 open-webbridge status。当 extension_connected 为 true 时，即可试跑页面上的命令，也可为助手安装可选的 Agent Skill。

常见问题

Open WebBridge 免费吗？

扩展和配套程序免费开源，使用 AGPL-3.0 许可。你选用的 AI 服务可能单独收费。

哪些 AI 助手可以用？

能在你的电脑上运行命令的 AI 助手，例如本地编程助手，都可以在 Chrome 连接后调用 open-webbridge 命令行工具。

浏览器数据如何处理？

扩展通过本机回环地址连接配套程序，无遥测。工具结果由你选用的 AI 助手处理。配套程序会访问 GitHub 检查软件更新。

为什么需要调试权限？

Open WebBridge 使用 Chrome DevTools Protocol 读取页面结构，并执行你请求的网页操作。可以查看权限和隐私说明。
