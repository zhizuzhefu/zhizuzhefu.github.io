让 AI Agent 控制本机 ChromeGive a local AI agent control of Chrome

连接扩展后，Codex CLI、Claude Code 等能运行本地命令的 AI 助手可以使用 Open WebBridge。先在终端试跑下面两条命令，确认能打开网页并读取页面结构，再让助手调用。Once the extension is connected, agents that can run local commands, such as Codex CLI and Claude Code, can use Open WebBridge. Try these two commands in a terminal to verify you can open a page and read its structure, then have the agent call them.

open-webbridge call navigate --session demo --args '{"url":"https://example.org","newTab":true}'

open-webbridge call snapshot --session demo

常见问题Common questions

Open WebBridge 免费吗？Is Open WebBridge free?

扩展和配套程序均免费开源，使用 AGPL-3.0 许可。AI 服务的费用由你选择的提供方决定。The extension and companion program are free and open source under the AGPL-3.0 license. Your AI provider may charge separately.

AI Agent 可以使用我已有的登录状态吗？Can an AI agent use my existing Chrome login?

可以。扩展在你安装它的 Chrome 配置中执行操作，沿用该配置已有的登录会话。你可以让助手读取已经登录的看板、填写表单或导出报表。Yes. The extension runs actions in the Chrome profile where you install it and uses that profile's existing login sessions. An agent can read a dashboard you're signed in to, fill forms, or export reports.

为什么要用 Chrome 调试权限？Why does Chrome ask for debugger access?

扩展借助 Chrome DevTools Protocol 读取页面结构并执行你请求的操作。扩展通过本机回环地址连接配套程序，无遥测。工具结果由你选用的 AI 助手处理。The extension uses the Chrome DevTools Protocol to read page structure and carry out requested actions. It connects to the companion program over loopback and has no telemetry. Your chosen AI agent controls how it processes tool results.
