AI browser automation in your own Chrome

Open WebBridge is a free, open-source Chrome extension. It gives your AI agent a way to read pages, click, fill forms, and export screenshots in the browser profile you already use.

Install Chrome extension Set up the companion app

Desktop Chrome · macOS, Linux, and Windows · No Open WebBridge account

Try a browser command

open-webbridge call navigate --session demo --args '{"url":"https://example.org","newTab":true}'
open-webbridge call snapshot --session demo

What can an AI agent do in Chrome?

Use a signed-in session

Read a dashboard or export a report in the Chrome profile where you already signed in.

Read and interact with a page

Inspect an accessibility snapshot, click controls, fill fields, or save a screenshot or PDF.

Annotate a live page

Attach a comment to an element so an agent can find the exact control you want it to review.

Install Open WebBridge

The extension and the companion program run together on the computer that runs Chrome.

  1. Add the Chrome extension

    Open the official Chrome Web Store listing in desktop Chrome and select Add to Chrome.

  2. Install the companion program

    On macOS or Linux, run the project installer in your terminal.

    curl -fsSL https://raw.githubusercontent.com/zhizuzhefu/open-webbridge/main/scripts/install.sh | bash

    On Windows, download the right executable and follow the PowerShell setup steps.

    • Windows x64
    • Windows ARM64
    • All downloads

  3. Connect Chrome

    Run open-webbridge url. Paste the URL into the extension popup and select Connect.

  4. Verify and try your first command

    Run open-webbridge status. When extension_connected is true, try the browser commands above or add the optional agent skill.

Common questions

Is Open WebBridge free?

Yes. The extension and companion program are free and open source under the AGPL-3.0 license. Your AI provider may charge separately.

Which AI agents can use it?

An agent that can run shell commands on your computer can call the open-webbridge CLI. For example, a local coding agent can run these commands after you connect Chrome.

How is browser data handled?

The extension connects to the companion program on your computer over loopback and has no telemetry. Your chosen AI agent controls how it processes results. The companion program checks GitHub for software updates.

Why does Chrome ask for debugger access?

Open WebBridge uses the Chrome DevTools Protocol to read the page structure and carry out requested browser actions. See the permission and privacy details.
