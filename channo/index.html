Channo · 自有源 IPTV / M3U 播放器

只播你自己的源

Channo 是一款 iPhone / iPad 上的 IPTV 播放器：导入你自己的 M3U、Xtream 或单条地址，用双引擎（AVPlayer → FFmpeg）稳定播放。停车时走官方 CarPlay 视频，行驶时自动转音频。不做网页嗅探、不做 DLNA、不做 VPN 隧道，也不内置任何频道。

M3U / Xtream / 单 URL 双引擎 AV → FFmpeg CarPlay 音频 + 视频（视频 entitlement 申请中） 用户 XMLTV 节目单 本地钥匙串存账号 iCloud 默认同步关闭 iPhone + iPad 无内置频道
English

Your sources, your player

Channo plays IPTV playlists you bring: M3U, Xtream, or a single stream URL. Dual engines (AVPlayer → FFmpeg) keep playback resilient. Parked CarPlay video, driving audio. No web sniffing, no DLNA, no VPN tunnel, no built-in channels.

What it does / 能做什么
简体中文
  • 导入 M3U 链接 / 文件、Xtream Codes、单条流地址
  • 自定义请求头（User-Agent / Referer 等）
  • 双引擎：优先系统 AVPlayer，必要时自动切到 LGPL FFmpeg
  • 用户自备 XMLTV；支持 gzip 节目单
  • 收藏、最近播放、频道体检；密码只进本机钥匙串
  • iPad 乘客模式与手机遥控（同一 Wi‑Fi / 热点）
English
  • Import M3U URL/file, Xtream Codes, or a single stream
  • Per-source HTTP headers (User-Agent / Referer / …)
  • Dual engines: AVPlayer first, LGPL FFmpeg on fallback
  • User-supplied XMLTV, including gzip
  • Favorites, recents, health checks; passwords in Keychain only
  • iPad passenger mode + phone remote on the same Wi‑Fi / hotspot
What it does not do / 明确不做
简体中文
  • 不内置频道、台标或官方 EPG
  • 不做网页视频嗅探 / 破解 DRM
  • 不做 DLNA / Packet Tunnel / 车机内浏览器绕过
  • 不提供任何付费节目内容；内容版权由你自行保证
English
  • No built-in channels, logos, or official EPG
  • No web sniffing / DRM circumvention
  • No DLNA / Packet Tunnel / in-car browser workarounds
  • No paid programming; you are responsible for content rights
Privacy in one line / 隐私一句话
简体中文

来源、账号、节目单默认只在本机。远程诊断分析默认关闭，需你在设置里主动打开。详见 隐私政策；FFmpeg 等开源声明见 开源许可。

English

Sources, credentials, and guide data stay on-device by default. Remote diagnostics are off unless you opt in in Settings. See the Privacy Policy and open-source licenses.
