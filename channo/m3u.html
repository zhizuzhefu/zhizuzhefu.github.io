在 iPhone 上添加 M3U / M3U8 播放列表Add an M3U or M3U8 playlist on iPhone

Channo 播放你已经拥有的播放列表。它不提供、不收录、也不代下任何 M3U 列表。下面是在 iPhone 或 iPad 上从链接或文件导入的步骤。Channo plays a playlist you already have. It does not provide, host or download any M3U list. These steps import a link or a file on iPhone or iPad.

用链接导入Import from a link

  1. 安装 Channo 后，打开来源，选择「M3U 列表」。
  2. 粘贴完整地址。地址以 http 或 https 开头，明文 http 可以播放。不要漏掉端口、路径或参数。
  3. 名称可以留空。如果对方另外给了节目单，把 XMLTV 地址填在同一页，支持 .xml 和 .gz。
  4. 列表很大时，先按分组勾选要导入的频道。Channo 会抽样检测前面一部分，其余在播放时再检测。
  5. 导入完成后，到频道页点「全部检测」，用「可播放 / 失效」筛掉打不开的条目。
  1. After you install Channo, open Sources and choose M3U playlist.
  2. Paste the full address. It starts with http or https. Cleartext HTTP can play. Keep the port, path and query.
  3. The name can stay empty. If you also have a guide, put the XMLTV address on the same screen. .xml and .gz are supported.
  4. On a large list, select the groups you want. Channo spot-checks the first portion. The rest are checked when you play them.
  5. After import, open Channels and tap Check All. Filter by Playable or Failed to set aside addresses that do not open.

用文件导入Import from a file

在「文件」里找到 .m3u、.m3u8 或 .txt，分享或打开到 Channo。文件会复制到 App 自己的存储中，之后刷新仍能读到。也可以用 channo://add?url= 把一条 http(s) 链接交回来源添加流程。In Files, find a .m3u, .m3u8 or .txt file and share or open it in Channo. The file is copied into the app's own storage, so a later refresh can still read it. A channo://add?url= link also hands an http or https address to the add-source flow.

单条视频地址是另一种入口，支持 http、https、rtmp、rtmps、rtsp、udp 和 rtp。播放列表本身请用 M3U 入口。A single video URL is a separate entry. It can use http, https, rtmp, rtmps, rtsp, udp or rtp. Use the M3U entry for a playlist.

导入之后After import

  • 1.2.1 起，免费版最多 3 个播放列表。Pro 不限数量。已经添加的列表在额度变化后仍可编辑和刷新。From version 1.2.1, the free version holds 3 playlists. Pro removes that limit. Playlists already added stay editable and refreshable if the allowance changes.
  • 来源详情里可以改地址、设置自动刷新。默认每 12 小时，也可改为 1、6、24 小时或手动。刷新失败时仍显示上次的频道。Source details can change the address and set auto-refresh. The default is every 12 hours. You can choose 1, 6 or 24 hours, or manual. A failed refresh keeps the previous channels.
  • 对方要求特定客户端时，在请求头里每行写一项，格式为 Name: value，例如 User-Agent 或 Referer，然后点立即刷新。When a provider expects a specific client, add one header per line as Name: value, such as User-Agent or Referer, then tap Refresh now.
  • 节目单按 tvg-id、tvg-name 或频道显示名匹配。免费查看现在和接下来，Pro 可看全天。来源声明了回看时，节目页会出现「从头回看」。The guide matches tvg-id, tvg-name or the channel display name. Now and Next are free. Pro opens the full day. When the source declares catch-up, the programme page offers Watch from Start.

如果对方给的是服务器、用户名和密码，而不是一条播放列表链接，改用 Xtream Codes 登录。要在电视上打开同一个列表，看 Apple TV 设置。其余播放、下载和车机问题在 使用指南。If you were given a server, username and password instead of a playlist link, use Xtream Codes login. To open the same list on a television, see Apple TV setup. Playback, downloads and the car are in the setup guide.

常见问题Questions

M3U 和 M3U8 有什么区别？What is the difference between M3U and M3U8?

M3U 是播放列表。M3U8 通常是 HLS 播放列表，也可以是一条 UTF-8 编码的播放列表。Channo 两种都能作为链接或文件导入。An M3U file is a playlist. An M3U8 file is usually an HLS playlist, and it can also be a UTF-8 playlist. Channo imports either one as a link or as a file.

可以直接打开手机里的播放列表文件吗？Can I open a playlist file already on my iPhone?

可以。从文件 App 分享或打开 .m3u、.m3u8 或 .txt，Channo 会把它复制到自己的存储里再导入。Yes. Share or open a .m3u, .m3u8 or .txt file from the Files app. Channo copies it into its own storage and then imports it.

M3U 地址返回 403 怎么办？The M3U address returns 403. What now?

在来源详情的请求头里按 Name: value 补上对方要求的 User-Agent 或 Referer，然后立即刷新。Add the User-Agent or Referer the provider requires, one per line as Name: value in the source details, then tap Refresh now.

导入了 M3U，为什么没有节目单？I imported an M3U. Why is there no guide?

M3U 本身通常不含节目时间。需要另填你自己的 XMLTV 地址，支持 .xml 和 .gz。频道按 tvg-id、tvg-name 或名称匹配。An M3U file usually carries no schedule. Enter your own XMLTV address (.xml or .gz). Channels match by tvg-id, tvg-name or display name.
