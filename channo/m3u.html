iPhone · iPad · M3U / M3U8

在 iPhone 上添加 M3U / M3U8 播放列表

Channo 播放你已经拥有的播放列表。它不提供、不收录、也不代下任何 M3U 列表。下面是在 iPhone 或 iPad 上从链接或文件导入的步骤。

在 App Store 下载 Channo免费下载 · 不包含播放列表

用链接导入

  1. 安装 Channo 后，打开来源，选择「M3U 列表」。
  2. 粘贴完整地址。地址以 http 或 https 开头，明文 http 可以播放。不要漏掉端口、路径或参数。
  3. 名称可以留空。如果对方另外给了节目单，把 XMLTV 地址填在同一页，支持 .xml 和 .gz。
  4. 列表很大时，先按分组勾选要导入的频道。Channo 会抽样检测前面一部分，其余在播放时再检测。
  5. 导入完成后，到频道页点「全部检测」，用「可播放 / 失效」筛掉打不开的条目。

用文件导入

在「文件」里找到 .m3u、.m3u8 或 .txt，分享或打开到 Channo。文件会复制到 App 自己的存储中，之后刷新仍能读到。也可以用 channo://add?url= 把一条 http(s) 链接交回来源添加流程。

单条视频地址是另一种入口，支持 http、https、rtmp、rtmps、rtsp、udp 和 rtp。播放列表本身请用 M3U 入口。

导入之后

  • 1.2.1 起，免费版最多 3 个播放列表。Pro 不限数量。已经添加的列表在额度变化后仍可编辑和刷新。
  • 来源详情里可以改地址、设置自动刷新。默认每 12 小时，也可改为 1、6、24 小时或手动。刷新失败时仍显示上次的频道。
  • 对方要求特定客户端时，在请求头里每行写一项，格式为 Name: value，例如 User-Agent 或 Referer，然后点立即刷新。
  • 节目单按 tvg-id、tvg-name 或频道显示名匹配。免费查看现在和接下来，Pro 可看全天。来源声明了回看时，节目页会出现「从头回看」。

如果对方给的是服务器、用户名和密码，而不是一条播放列表链接，改用 Xtream Codes 登录。要在电视上打开同一个列表，看 Apple TV 设置。其余播放、下载和车机问题在 使用指南。

常见问题

M3U 和 M3U8 有什么区别？

M3U 是播放列表。M3U8 通常是 HLS 播放列表，也可以是一条 UTF-8 编码的播放列表。Channo 两种都能作为链接或文件导入。

可以直接打开手机里的播放列表文件吗？

可以。从文件 App 分享或打开 .m3u、.m3u8 或 .txt，Channo 会把它复制到自己的存储里再导入。

M3U 地址返回 403 怎么办？

在来源详情的请求头里按 Name: value 补上对方要求的 User-Agent 或 Referer，然后立即刷新。

导入了 M3U，为什么没有节目单？

M3U 本身通常不含节目时间。需要另填你自己的 XMLTV 地址，支持 .xml 和 .gz。频道按 tvg-id、tvg-name 或名称匹配。
