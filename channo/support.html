Getting started / 开始使用

简体中文
  • 打开「来源」→ 添加 M3U URL / 文件、Xtream 或单条地址
  • 若源要求特定 UA / Referer，在来源的请求头里填写
  • 节目单：添加你自己的 XMLTV 地址（支持 .gz）
  • http 明文源可以播放；请只导入你有权使用的源
English
  • Sources → add M3U URL/file, Xtream, or a single stream
  • Set custom User-Agent / Referer in source headers when required
  • Guide: add your own XMLTV URL (gzip supported)
  • Cleartext HTTP sources can play; only import streams you have rights to

Playback / 播放

简体中文
  • 默认自动：AVPlayer 优先，失败或特定格式切 FFmpeg
  • 设置里可强制指定引擎以便排查
  • CarPlay 支持车载音频；停车视频取决于兼容系统、车机能力与车机是否允许，行驶时只播放音频
English
  • Auto mode: AVPlayer first, FFmpeg on failure / certain formats
  • Force an engine in Settings while debugging
  • CarPlay supports audio. Parked video requires a compatible system and vehicle permission; driving uses audio only

免费与 Pro / Free and Pro

免费添加 3 个播放列表，使用收藏、搜索、基础播放和「现在 / 接下来」节目单。Pro 一次购买，无订阅；可在购买页或设置中恢复购买。点播离线下载不支持直播录制，节目单需要自备 XMLTV 来源。

Channo 没有内置频道。在 App Store 下载 Channo，导入你有权使用的播放列表后开始观看。

Add 3 playlists free, with favorites, search, basic playback and the Now/Next guide. Pro is a one-time purchase, with no subscription. Restore Purchases is available on the paywall and in Settings. Downloads support eligible on-demand content, not live recording. Guide features require your own XMLTV source.

Channo has no built-in channels. Download Channo on the App Store, then add sources you have the right to use.
