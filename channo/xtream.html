Xtream Codes · iPhone · Apple TV

在 iPhone 和 Apple TV 上登录 Xtream CodesSign in to Xtream Codes on iPhone and Apple TV

当内容提供方给你的是服务器地址、用户名和密码，而不是一条播放列表链接时，用 Xtream 登录。Channo 不提供 Xtream 账号，也不提供频道。Use Xtream when your provider gave you a server address, username and password, not a single playlist link. Channo does not provide an Xtream account, and it does not include channels.

在 iPhone 或 iPad 上登录Sign in on iPhone or iPad

  1. 打开来源，选择 Xtream。
  2. 服务器填 http 或 https 地址，例如 http://主机:端口。没有写协议时，Channo 会按 http 理解。其他协议不能作为 Xtream 服务器。
  3. 填写用户名和密码。名称只是给你自己看的标签，可以留空。
  4. 保存后，这个来源会计入播放列表额度。免费版最多 3 个，Pro 不限数量。
  5. 直播出现在频道里。影片和剧集可以在影片页浏览，并从头播放。从上次停下的位置继续，需要 Pro。
  1. Open Sources and choose Xtream.
  2. Enter an http or https server, for example http://host:port. If you omit the scheme, Channo treats it as http. Other schemes cannot be the Xtream server.
  3. Enter the username and password. The name is only a label for you and can stay empty.
  4. After you save, this source counts toward the playlist allowance. The free version holds 3. Pro removes the limit.
  5. Live channels appear in Channels. Movies and series can be browsed and played from the start. Resume from where you stopped is part of Pro.

密码存在哪里Where the password is stored

独立的 Xtream 密码保存在系统钥匙串，不会放进 Channo 的 iCloud 播放列表记录。打开 iCloud 同步后，来源名称、地址和点播进度可以进入你的私有 iCloud；地址里的令牌仍可能一起同步。A separate Xtream password stays in the system Keychain. It is not placed in Channo's iCloud playlist record. With iCloud sync on, the source name, address and on-demand progress can go to your private iCloud. A token inside the address can still sync with that address.

如果这台 Apple ID 开启了 iCloud 钥匙串，系统可能把钥匙串项加密同步到同一账号下的 iPhone、iPad 和 Apple TV。Apple TV 上还没有密码时，会再询问一次。If iCloud Keychain is on for this Apple ID, the system may encrypt and sync the Keychain item to iPhone, iPad and Apple TV on the same account. If Apple TV does not have the password yet, it asks once.

和 M3U 怎么选Xtream or M3U

对方给了服务器、用户名和密码，用本页的 Xtream 登录，直播、影片和剧集会分开出现。对方只给了一条很长的播放列表网址，不要自行拆出账号，整段粘贴到 M3U 导入。A server, username and password belong on this page. Live channels, movies and series then appear separately. A single long playlist URL should be pasted whole on the M3U setup page. Do not pull a login out of that URL yourself.

节目单如果没有随账号出现，在来源详情里另填 XMLTV 地址。要在客厅播放，继续看 Apple TV 设置。If a guide does not arrive with the account, add an XMLTV address in the source details. To watch in the living room, continue with Apple TV setup.

常见问题Questions

只有一条很长的播放列表链接，能当 Xtream 登录吗？I only have one long playlist link. Can that be an Xtream login?

不要拆开链接去猜账号。对方如果给的是一条 http(s) 播放列表，用 M3U 方式整段粘贴。对方如果给的是服务器、用户名和密码，再用 Xtream 登录。Do not split the link to guess a username and password. If you were given one http or https playlist URL, paste the whole URL as M3U. Use Xtream only when you were given a server, username and password.

Xtream 密码会上传到 Channo 的服务器吗？Does Channo upload my Xtream password to its own server?

不会。Channo 没有账号系统。密码存在系统钥匙串，不会放进 iCloud 播放列表同步记录。若 Apple ID 开启了 iCloud 钥匙串，系统可能把它加密同步到你的其他设备。No. Channo has no account system. The password stays in the system Keychain and is not placed in the iCloud playlist record. If iCloud Keychain is on for the Apple ID, the system may encrypt and sync that item to your other devices.

登录后能看到影片和剧集吗？Will I see movies and series after login?

可以浏览该 Xtream 账号里的直播、影片和剧集，并从头播放。从上次位置续播需要 Pro。You can browse the live channels, movies and series in that Xtream account and play them from the start. Resume from the last position is part of Pro.

Xtream 登录失败怎么查？What should I check when Xtream login fails?

确认服务器是 http 或 https，并且包含主机名。用户名和密码不要多出空格。服务器拒绝访问时，先向内容提供方核对账号是否仍然有效。Confirm the server is http or https and includes a host name. Remove extra spaces from the username and password. If the server refuses the login, ask the provider whether the account is still valid.
