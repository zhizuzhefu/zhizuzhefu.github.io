Xtream Codes · iPhone · Apple TV

Sign in to Xtream Codes on iPhone and Apple TV

Use Xtream when your provider gave you a server address, username and password, not a single playlist link. Channo does not provide an Xtream account, and it does not include channels.

Sign in on iPhone or iPad

  1. Open Sources and choose Xtream.
  2. Enter an http or https server, for example http://host:port. If you omit the scheme, Channo treats it as http. Other schemes cannot be the Xtream server.
  3. Enter the username and password. The name is only a label for you and can stay empty.
  4. After you save, this source counts toward the playlist allowance. The free version holds 3. Pro removes the limit.
  5. Live channels appear in Channels. Movies and series can be browsed and played from the start. Resume from where you stopped is part of Pro.

Where the password is stored

A separate Xtream password stays in the system Keychain. It is not placed in Channo’s iCloud playlist record. With iCloud sync on, the source name, address and on-demand progress can go to your private iCloud. A token inside the address can still sync with that address.

If iCloud Keychain is on for this Apple ID, the system may encrypt and sync the Keychain item to iPhone, iPad and Apple TV on the same account. If Apple TV does not have the password yet, it asks once.

Xtream or M3U

A server, username and password belong on this page. Live channels, movies and series then appear separately. A single long playlist URL should be pasted whole on the M3U setup page. Do not pull a login out of that URL yourself.

If a guide does not arrive with the account, add an XMLTV address in the source details. To watch in the living room, continue with Apple TV setup.

Questions

I only have one long playlist link. Can that be an Xtream login?

Do not split the link to guess a username and password. If you were given one http or https playlist URL, paste the whole URL as M3U. Use Xtream only when you were given a server, username and password.

Does Channo upload my Xtream password to its own server?

No. Channo has no account system. The password stays in the system Keychain and is not placed in the iCloud playlist record. If iCloud Keychain is on for the Apple ID, the system may encrypt and sync that item to your other devices.

Will I see movies and series after login?

You can browse the live channels, movies and series in that Xtream account and play them from the start. Resume from the last position is part of Pro.

What should I check when Xtream login fails?

Confirm the server is http or https and includes a host name. Remove extra spaces from the username and password. If the server refuses the login, ask the provider whether the account is still valid.
