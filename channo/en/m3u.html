Add an M3U or M3U8 playlist on iPhone

Channo plays a playlist you already have. It does not provide, host or download any M3U list. These steps import a link or a file on iPhone or iPad.

Download Channo on the App StoreFree download · playlists not included

Import from a link

  1. After you install Channo, open Sources and choose M3U playlist.
  2. Paste the full address. It starts with http or https. Cleartext HTTP can play. Keep the port, path and query.
  3. The name can stay empty. If you also have a guide, put the XMLTV address on the same screen. .xml and .gz are supported.
  4. On a large list, select the groups you want. Channo spot-checks the first portion. The rest are checked when you play them.
  5. After import, open Channels and tap Check All. Filter by Playable or Failed to set aside addresses that do not open.

Import from a file

In Files, find a .m3u, .m3u8 or .txt file and share or open it in Channo. The file is copied into the app’s own storage, so a later refresh can still read it. A channo://add?url= link also hands an http or https address to the add-source flow.

A single video URL is a separate entry. It can use http, https, rtmp, rtmps, rtsp, udp or rtp. Use the M3U entry for a playlist.

After import

  • From version 1.2.1, the free version holds 3 playlists. Pro removes that limit. Playlists already added stay editable and refreshable if the allowance changes.
  • Source details can change the address and set auto-refresh. The default is every 12 hours. You can choose 1, 6 or 24 hours, or manual. A failed refresh keeps the previous channels.
  • When a provider expects a specific client, add one header per line as Name: value, such as User-Agent or Referer, then tap Refresh now.
  • The guide matches tvg-id, tvg-name or the channel display name. Now and Next are free. Pro opens the full day. When the source declares catch-up, the programme page offers Watch from Start.

If you were given a server, username and password instead of a playlist link, use Xtream Codes login. To open the same list on a television, see Apple TV setup. Playback, downloads and the car are in the setup guide.

Questions

What is the difference between M3U and M3U8?

An M3U file is a playlist. An M3U8 file is usually an HLS playlist, and it can also be a UTF-8 playlist. Channo imports either one as a link or as a file.

Can I open a playlist file already on my iPhone?

Yes. Share or open a .m3u, .m3u8 or .txt file from the Files app. Channo copies it into its own storage and then imports it.

What if an M3U address returns 403?

In the source details, add the User-Agent or Referer the provider requires, one header per line as Name: value, then refresh now.

I imported an M3U playlist. Why is there no guide?

An M3U playlist usually has no programme times. Add your own XMLTV address. .xml and .gz are supported. Channels match tvg-id, tvg-name or the display name.
